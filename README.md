# OIBSIP — Oasis Infobyte Summer Internship Program

This repository holds my task submissions for the Oasis Infobyte Summer Internship Program (SIP), completed under the **Web Development & Designing** track.

> "Learning is the only thing the mind never exhausts, never fears, and never regrets." — Leonardo da Vinci

## About the internship

Oasis Infobyte runs a self-paced internship program across multiple tracks (Web Development, Android, Java, Data Science, Python, Data Analytics, Cyber Security, and Graphics Design). Interns choose a track, complete a set number of tasks against a standardised checklist, and submit each one as a self-contained project inside a single GitHub repository.

## Track & level

**Track:** Web Development & Designing
**Level completed:** Level 1 — *all 3 tasks required and completed*

The Web Development track offers 7 tasks split across 3 levels. The completion rule for this track is to choose **one** level and complete **every** task within it, rather than mixing tasks across levels.
